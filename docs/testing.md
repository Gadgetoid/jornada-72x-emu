# Tests

`make test` also runs `build/native-check`, which compares 10,000 randomized native memmove cases against libc, 256 calls against CE's ROM, 32 cache-sweep calls against CE, and verifies that a data-TLB miss is filled by native mapping. The boot suite cold boots, calibrates, completes the setup wizard, checks save/resume determinism and battery warnings, and compares an optimized 8-second cold boot with the baseline while requiring cache-sweep hits. It then launches Pocket Word, My Handheld PC, and Pocket Excel; each app must change the screen, match with optimisations on, exercise the fingerprinted memmove hook, and repeat deterministically. It plugs in the cable, waits for PC Link to start, installs debugmgr over RAPI and pings it through the mailbox, then again after a soft reset. With `../jornada-72x-tools` (or `JORNADA_TOOLS`), it builds `tests/comecho`, runs it over RAPI and checks that bytes sent to `--tcp-com4` come back through CE's COM4:. It builds `tests/atprobe` and checks the internal modem answers `ATI3`. It also builds `tests/tcpprobe`, inserts the Ethernet card and checks CE gets a DHCP lease, then soft resets with only the card and checks that the probe, started from `\Windows\StartUp`, exchanges a line with the host over TCP. It makes CompactFlash and PC Card images with `mkcard.sh`, inserts both into the desktop and saves a state, then loads that state with PC Link and checks over RAPI that CE mounts them as `\Storage Card` and `\Storage Card2`, that a file written on the host reads back, and that a file put over RAPI lands in the image; that the saved state keeps the cards and that ejecting them removes them from My Handheld PC. It suspends and wakes the machine with the On/Off key, types into Pocket Word, checks that `--speed=2` runs more instructions and that `--host-clock` sets the date. Finally it runs `jornada720 --net --agent --gdb` under SDL's dummy drivers, waits for it to install debugmgr by itself, quits it with SIGTERM and checks that the state was saved, then runs it with an empty data folder and checks that it makes a first machine, saves its state and that `--tcp` listens.

`make format` and `make format-check` run the pinned uncrustify from `requirements-style.txt`.

`make difftest` compares random ARM instructions against Unicorn's SA-1110 model (`pip install unicorn`). Unaligned accesses are skipped because QEMU doesn't follow the ARMv4 rules for them.
